ローカルLLMからコールするコマンドラインツール。
結果はjsonで返却する。

## 出力仕様

標準出力に、1行1件の JSON オブジェクトを返す。

| 項目 | 内容 |
|---|---|
| `kind` | 設定の列挙に含まれる英単語 |
| `ref` | 元データの ID。`kind` と組で重複判定する |
| `body` | LLM に渡す短く具体的な一文 |
| `priority` | 整数。省略時 0 |
| `expires_at` | 省略時は設定の既定期間 |

## 出力 JSON サンプル

```json
{"kind":"vuln","ref":"CVE-2026-0001","body":"OpenSSHに影響ありの脆弱性が1件。修正版は9.9p2","priority":2,"expires_at":"..."}
```

受け取ったJSONをどう処理するかは受け側に任せる。
